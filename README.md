# samochod-CAD
Model koncepcyjny 3D samochodu zabawki.
Projekt został naszkicowany i wykonany w programie Autodesk Inventor, całość składa się z kilku części połączonych ze sobą połączeniami wcisnanymi z zakresami tolerancji +/-0.1mm. Zabawka została wykonana
z plastiku ABS. Projekt obejmuje również model złożenia 3D, dokumentację techniczną montażu wraz z listą części oraz wizualną prezentację 360°.
— Zastosowanie wielu płaszczyzn i funkcji programu Inventor w celu nadania estetycznego wyglądu.
— Pełna lista części modelu (BOM).
— Tolerancja wcisków o marginesie +/- 0.1mm, zapewniają ciasne pasowanie.
